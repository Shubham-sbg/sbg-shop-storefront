SBG JERSEY TRANSPARENT PNG PACK

Contains 8 transparent PNG cutouts made from the supplied jersey mockup images. Original pixel artwork, names/numbers, logos, and colors are preserved. Only the surrounding background was removed.

IMPORTANT: These files are transparent 2D product renders with existing 3D-style fabric lighting/folds. This ZIP does NOT include actual .GLB/.GLTF 3D meshes or a fully rotatable 360-degree model. A true 360 model requires a garment mesh and correctly prepared front/back/sleeve texture maps; the supplied assets are rendered mockups, not full flat garment-print layouts.
