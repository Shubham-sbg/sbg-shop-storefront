# SBG SHOP Starter Pack v1.1 — Read This First

1. Keep this complete folder in the repository root; do not scatter the docs.
2. `AGENTS.md` defines rules for every AI coding agent.
3. `brain/` is the current project source of truth. Agents must read it before any task/change.
4. `SBG_SHOP_Product_Blueprint_v1.1.md` is the full blueprint; `docs/SBG_SHOP_Product_Blueprint_v1.0_BASELINE.md` preserves the prior baseline.
5. `references/visual/` contains the source video/contact sheet. `references/jersey-assets/` contains your supplied jersey mockups under readable filenames.
6. Current stage is research/reference intake only. Do not code yet.
7. The real payment gateway is intentionally deferred. Do not implement live payment or fake real-payment success.
8. Firebase is not automatically selected.
9. For Google AI Studio, start with `prompts/01_RESEARCH_GATE_GOOGLE_AI_STUDIO.md`. For Cursor/OpenCode/Antigravity/other agents, use `prompts/02_MASTER_AGENT_START_PROMPT.md` plus the same current-stage instructions.

Before moving stages, update `brain/CURRENT-STATE.md` and obtain the owner's review/sign-off for the current gate.
